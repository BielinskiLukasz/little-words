  <action>
    Step 1 — Create public/icons/lw-icon.svg using the Write tool.

    The SVG must have:
    - viewBox "0 0 512 512", width and height "512"
    - A rect covering the full 512x512 canvas with fill "#0D9488" (teal, per D-01/D-10)
    - A text element with: x="256", y="256", dominant-baseline="central", text-anchor="middle", font-family="Arial, Helvetica, sans-serif", font-weight="bold", font-size="220", fill="white"
    - Text content: LW
    - No external font references — use system fonts only (offline-safe)

    For the maskable variant the same SVG works because the teal rect already fills the full 512x512 canvas, satisfying the safe-zone bleed requirement (D-02).

    Step 2 — Create scripts/ directory if it does not exist, then create scripts/generate-icons.js using the Write tool.

    The script must:
    - Import Resvg from '@resvg/resvg-js' using require() (CommonJS)
    - Import fs and path from Node core
    - Read public/icons/lw-icon.svg as a UTF-8 string
    - Define an array of four output specs:
        * { file: 'icon-192.png', size: 192 }
        * { file: 'icon-512.png', size: 512 }
        * { file: 'apple-touch-icon.png', size: 180 }
        * { file: 'icon-512-maskable.png', size: 512 }
    - For each spec, construct a new Resvg(svgString, { fitTo: { mode: 'width', value: spec.size } }), call .render(), call .asPng() to get a Buffer, and write it to public/icons/{spec.file} using fs.writeFileSync
    - Log "Generated {spec.file}" after each file
    - The script resolves all paths relative to process.cwd() (run from repo root)

    Step 3 — Run: npm install --save-dev @resvg/resvg-js
    This adds @resvg/resvg-js to devDependencies and updates package-lock.json.
    @resvg/resvg-js is pure WebAssembly with no native binaries — it installs without compilation on all platforms.
  </action>
