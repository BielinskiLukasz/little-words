# API Coverage — Phase 05: PWA Polish

Phase 05 integrates no external third-party APIs. All referenced APIs are
browser-native Web Platform APIs managed transparently by Workbox/vite-plugin-pwa.

| Capability | Decision | Reason |
|------------|----------|--------|
| Service Worker API | OPT-OUT | Browser-native platform API; no external service; all SW logic generated by Workbox via vite-plugin-pwa |
| Web App Manifest | OPT-OUT | Static JSON config emitted at build time; no network calls; no third-party service |
| GitHub Actions deploy pipeline | OPT-OUT | Deployment infrastructure only; not an app-level API integration; no runtime calls from the app |
| @resvg/resvg-js (icon generation) | OPT-OUT | WASM library used once at build time to rasterize SVG → PNG; not called at runtime; no network dependency |
