**Database Queries:**
Extend meaning.service.ts with aggregation functions:

1. `getMeaningsByMonth(startDate?: Date, endDate?: Date): Promise<Array<{month: string, count: number}>>` — query all active meanings, group by YYYY-MM of firstUseDate, count per month, filtered by date range

- Aggregation should return all months in the range, even if some months have 0 new meanings (the timeline should not have gaps)
