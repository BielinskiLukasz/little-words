# Phase 3 — UI Design Contract: Browse Views

> Visual and interaction contract for dashboard, list, and detail view pages. Generated by gsd-ui-researcher, verified by gsd-ui-checker.
> 
> **Phase Goal:** A parent can review all entered data through Dashboard, Meanings, Word Forms, Categories, and Timeline views — the full data model is observable and editable via Active/Inactive toggle and lastUseDate picker.

## Spacing Scale

Declared values (all multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon inline spacing, tightly grouped elements |
| sm | 8px | Compact element spacing (gaps between chips, small padding) |
| md | 16px | Default element spacing (list item padding, button padding, card internal padding, form field gaps) |
| lg | 24px | Section padding (page margins, gaps between major sections, card external gaps) |
| xl | 32px | Layout gaps (spacing between cards in grid, detail page section breaks) |
| 2xl | 48px | Major section breaks (distance between major page sections) |
| 3xl | 64px | Page-level spacing (top padding on pages, hero card spacing) |

**Exceptions:** None for Phase 3. All layout uses the 8-point scale exclusively.

**Sensible Defaults Applied (no explicit override needed):**
- List item row height: 16px padding top/bottom (md) = ~48px total with text
- Dashboard card padding: 16px internal (md), 24px gaps between cards (lg)
- Detail page margins: 24px (lg) page padding
- Button internal padding: 8px vertical (sm) × 16px horizontal (md)

## Color

**60/30/10 Split:**

| Role | Value | Usage |
|------|-------|-------|
| **Dominant (60%)** | OKLCH warm neutral: `oklch(98.5% 0.005 80)` light / `oklch(12% 0.005 80)` dark | Page backgrounds, large surfaces, default component backgrounds |
| **Secondary (30%)** | OKLCH warm neutral: `oklch(94% 0.01 80)` light / `oklch(22% 0.005 80)` dark | Card backgrounds, list item backgrounds, sidebar/secondary surfaces, input fields |
| **Accent (10%)** | Teal primary: `oklch(55% 0.15 185)` light / `oklch(65% 0.15 185)` dark | Interactive focus states, active nav indicators, "Review these?" section accent text, primary CTA buttons, toggle switch "on" state, meaningful icon highlights |
| **Destructive** | Warm red: `oklch(60% 0.22 25)` | Destructive actions only (delete button, confirmation alert text) |

**Accent Reserved For (10% allocation):**
1. **Interactive focus states** — border/ring on focused form inputs, tabs, buttons
2. **Active bottom nav tab** — the current tab indicator (Dashboard/Meanings/Word Forms/More)
3. **"Review these?" section** — the section title or highlight accent
4. **Primary CTA buttons** — "Save", "Link", navigation CTAs (background color)
5. **Toggle switches in "on" state** — the Switch component when toggled to Active
6. **Meaningful icon highlights** — category badge accents, status icons

**NOT reserved for accent:** General body text links (use primary/secondary/muted hierarchy), secondary buttons (use secondary background), table borders (use border token).

**Semantic Colors Already Configured in index.css:**
- `--foreground`: dark text (oklch 20%)
- `--card-foreground`: card text (oklch 20%)
- `--muted-foreground`: secondary text (oklch 55%)
- `--destructive`: warm red for alerts/deletions
- `--border`: light borders (oklch 90%)
- `--ring`: focus ring (teal, same as primary)

## Copywriting Contract

All copy must use `useTranslation('common')` from react-i18next. Keys should match this contract exactly for i18n consistency.

| Element | English Copy | Context |
|---------|--------------|---------|
| **Primary CTA (List views)** | "Add meaning" (on Meanings), "Add word form" (on Word Forms) | FAB button or page-level action; opens sheet or form |
| **Primary CTA (Dashboard)** | "Add your first meaning" | When no meanings exist; directs to word entry flow |
| **Empty state heading (Meanings list)** | "No meanings yet" | Rendered when `meanings.length === 0` |
| **Empty state body (Meanings list)** | "No meanings yet. Add your first one with the + button." | Actionable copy pointing to FAB |
| **Empty state heading (Word Forms list)** | "No word forms yet" | Rendered when `wordForms.length === 0` |
| **Empty state body (Word Forms list)** | "No word forms yet. Add your first one with the + button." | Actionable copy pointing to FAB |
| **Empty state heading (Categories)** | "No meanings yet" | Rendered when no meanings exist to categorize |
| **Empty state body (Categories)** | "No meanings yet. Add your first one with the + button." | Consistent messaging across list views |
| **Empty state heading (Timeline)** | "No data yet" | Rendered when timeline query returns empty |
| **Empty state body (Timeline)** | "No data yet. Log meanings to see growth." | Encourages feature adoption; "growth" ties to app value |
| **"Review these?" empty state** | "All meanings used recently — great job!" | Positive, warm tone; celebrates user behavior |
| **Generic error state** | "Something went wrong. Try refreshing." | Displayed when fetch or render fails; encourages page reload action |
| **Detail page empty (linked items)** | "No word forms linked yet." (Meaning detail) / "No meanings linked yet." (Word Form detail) | Shown when a detail page has no related records |
| **Destructive action: Word Form delete** | Button label: "Delete" / Confirmation heading: "Delete word form?" / Confirmation body: "This will remove the word form, but linked meanings will stay. Continue?" | Transaction-safe UX; clarifies side effects |
| **Destructive action: Confirm button** | "Delete" (secondary action) / "Cancel" (primary action in dialog) | Dialog action buttons; "Delete" is destructive variant, "Cancel" closes |
| **Active/Inactive toggle label** | "Active" (shown with Switch component) | Toggle on Meaning detail page; informs state change |
| **"See all" link (Dashboard)** | "See all [N]" | Links from "Review these?" section to full Meanings list |
| **Sort toggle (Meanings/Word Forms)** | "Newest first" (default) / "A–Z" (alphabetical) | Toggle button at top of list; switches `sortOrder` state |
| **Category filter chip (Meanings)** | "Filtering: [Category name] ×" | Badge displayed when category query param is active; × clears filter |
| **Timeline view toggle** | "Growth rate" (bar chart) / "Total vocabulary" (line chart) | Tab toggle above Timeline chart; switches visualization |
| **Timeline date range** | "Last 6 months" / "Last 12 months" / "All time" | Dropdown selector above Timeline; sets aggregation period |

**Tone & Consistency:**
- **Warm, encouraging:** "great job!", "Let's track", "No meanings yet" (not "empty", "zero", "failed")
- **Transparent about actions:** Confirmation dialogs always clarify what happens ("linked meanings will stay")
- **Action-oriented:** Empty states point toward next step ("Add your first one with the + button")
- **Privacy-forward:** No analytics language; no "learn more" links to external docs

## UI Considerations

State coverage for Phase 3 list and detail views. Shape-rooted UI states (empty, populated, overflow, long-text, loading).

| Category | Element(s) | Status | Resolution |
|----------|------------|--------|-----------|
| **empty** | Meanings list, Word Forms list, Categories, Timeline | ✅ covered | Empty state message with actionable copy as per Copywriting Contract |
| **populated** | Meanings list with 1+ items, Word Forms list with 1+ items | ✅ covered | List renders rows with sort toggle (Newest first/A–Z default); rows are tappable |
| **overflow** | List view when >20 items (Meanings, Word Forms) | ✅ covered | Scrollable container; no pagination in v1; sort toggle helps navigation |
| **long-text** | Meaning text on Meanings list, Word Form text on Word Forms list | ✅ covered | Body text (16px, 1.5 line-height); truncate at 2–3 lines with ellipsis if needed; full text visible on detail page |
| **long-text** | Category name in Categories view | ✅ covered | Label text (14px); all category names fit in single line (max 25 chars in English/Polish) |
| **long-text** | Dashboard hero card "Active Meanings" count | ✅ covered | Display size (28px, 1.1 line-height); number-only, no truncation needed |
| **filtered** | Meanings list with category filter active | ✅ covered | Filter chip ("Filtering: [Category] ×") displayed; × clears filter; list re-renders filtered results |
| **loading** | First Dashboard load (useLiveQuery warming up) | ✅ covered | App-level splash screen (established Phase 1) shown during DB startup; Dashboard renders immediately after |
| **loading** | Timeline chart data aggregation | 🧪 backstop | Assume data aggregation is synchronous (Dexie query); no explicit loading spinner (verified in plan phase) |
| **error** | Dexie query fails (list fetch fails) | ✅ covered | Generic error message rendered via ErrorBoundary; "Something went wrong. Try refreshing." |
| **error** | Detail page record deleted while viewing | 🧪 backstop | Assume deletion prevents detail page access (navigation validation); if accessed, show "Record not found" error (verified in plan phase) |
| **transition** | Meaning Active/Inactive toggle on detail page | ✅ covered | Switch component state change is immediate; no confirmation needed; `lastUseDate` update via date picker (separate action) |
| **zero-one-many** | "Review these?" dashboard section (meanings unused 30+ days) | ✅ covered | Shows 0 items → positive empty message; 1–3 items → list rendered; >3 items → "See all [N]" link to Meanings list |
| **zero-one-many** | Timeline chart data points | ✅ covered | 0 points → empty state; 1+ points → bar chart (Growth rate) + line chart (Total vocabulary); both views available via tab toggle |

## Key Integration Points

**Routes Added (child of RootLayout):**
- `{ path: 'meanings/:id', element: <MeaningDetailPage /> }`
- `{ path: 'word-forms/:id', element: <WordFormDetailPage /> }`

**Query Parameters (on existing pages):**
- `MeaningsPage` reads `?category=CategoryName` for category filtering
- Category filter applied via Badge chip; × clears via `useSearchParams().set()`

**Service Functions (pre-existing, used as-is):**
- `toggleMeaningActive(id: number, isActive: boolean)` — Meaning detail page Switch component
- `deleteWordForm(id: number)` — Word Form detail page delete confirmation
- `searchMeanings(prefix: string)` — autocomplete (Phase 2)
- `findOrCreateWordForm(text: string)` — word entry (Phase 2)

**Service Functions (NEW, to be added):**
- `getMeaningById(id: number): Meaning`
- `updateLastUseDate(id: number, date: Date): Promise<void>`
- `getMeaningsUnusedFor30Days(): Promise<Meaning[]>` — Dashboard Review These
- `getWordFormById(id: number): WordForm`
- `getMeaningsGroupedByCategory(): Promise<{[category: string]: number}>` — Categories page
- `getVocabularyGrowthTimeline(startDate?: Date, endDate?: Date)` — Timeline aggregation

**Zustand Store (UI state, no persistence):**
- `sortOrder: 'newest' | 'alphabetical'` (local component state, resets per navigation)
- `selectedDateRange: '6m' | '12m' | 'all'` (local state on Timeline page)
- `activeTimelineView: 'growth' | 'total'` (local state on Timeline page)
- `selectedCategory: string | null` (derived from query param, not stored in Zustand)
