## Spacing Scale

Standard 8-point scale in use across the project. No Phase 6 exceptions beyond the existing 44px touch-target minimum on interactive chips.

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gap inside chip; inline badge padding |
| sm | 8px | Compact element spacing; gap between pair chips in a row |
| md | 16px | Default section padding; input padding; card body padding |
| lg | 24px | Section padding on detail pages; Pairs list row vertical padding |
| xl | 32px | Layout gap between page header and content body |
| 2xl | 48px | Major section breaks (e.g. between report sections) |
| 3xl | 64px | Page-level bottom padding (above bottom nav) |

Exceptions:
- Touch targets for tappable chips (word form chip, meaning chip, nav arrow) must be minimum 44px height to meet mobile touch standards.
- Bottom nav area: existing 64px safe area from Phase 3 — unchanged.

## Typography

Three sizes declared. Two primary weights declared. Source: established patterns in `src/pages/MeaningDetailPage.tsx` and `src/shared/components/BottomNav.tsx`.

| Role | Size | Weight | Line Height | Tailwind class |
|------|------|--------|-------------|----------------|
| Display | 24px | 700 (bold) | 1.25 | `text-2xl font-bold` |
| Body | 16px | 400 (regular) | 1.5 | `text-base` |
| Label | 14px | 400 (regular) | 1.5 | `text-sm` |

Notes:
- Display: page headings (h1) only — Meanings detail, Word Forms detail, Pairs page, Doctor Report page.
- Body: main content text — meaning text in read mode, word form text in read mode, report body.
- Label: form field labels, input placeholder text, chip text, sort selector options, category badge text, metadata dates, isActive toggle label, Edit/Save changes/Discard changes button labels, nav tab labels.
- `text-muted-foreground` applies to secondary/supporting label text; it does not change font size or weight.

## Color

Tokens declared in `src/index.css` using OKLCH color space. Both light and dark modes are defined; Phase 6 introduces no new color tokens.

| Role | CSS Variable | Light Value | Usage |
|------|-------------|-------------|-------|
| Dominant (60%) | `--background` | oklch(98.5% 0.005 80) | Page background; behind all content |
| Secondary (30%) | `--card` / `--secondary` | oklch(100% 0 0) / oklch(94% 0.01 80) | Cards (Dashboard stat cards, Pairs rows, detail page panels); sheet background |
| Accent / Primary (10%) | `--primary` | oklch(55% 0.15 185) | Reserved elements only (see below) |
| Destructive | `--destructive` | oklch(60% 0.22 25) | Destructive actions only (delete confirmation) |

Accent (`--primary`, teal) reserved for:
- Save button (primary variant) in inline edit mode
- Bottom nav active tab indicator
- Link/navigation chips on Pairs rows (chip border or text highlight)
- Focus ring (`--ring`) on interactive inputs and buttons
- Dashboard stat card hover state (Link wrapper)

Accent must NOT be applied to: read-only text, inactive badges, metadata dates, sort selector idle state, or the Edit/Cancel buttons (use outline or ghost variant instead).

Dark mode: all tokens have dark equivalents in the existing `@media (prefers-color-scheme: dark)` block. Phase 6 must not hard-code light-mode values.
