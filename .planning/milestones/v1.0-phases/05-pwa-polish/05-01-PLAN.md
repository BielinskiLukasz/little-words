## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| SW → App | Service worker delivers new JS bundles; a compromised SW could serve malicious assets |
| CDN/GitHub Pages → Browser | Static file delivery; HTTPS prevents MITM but asset integrity is not verified at runtime |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-05-01 | Tampering | Service Worker update flow | medium | mitigate | registerType: 'prompt' ensures the new SW only activates after explicit user consent (updateServiceWorker(true)); the user sees the toast before any update applies |
| T-05-02 | Spoofing | toast() with duration: Infinity | low | accept | Sonner renders inside the app's own DOM; there is no cross-origin script involved in the toast mechanism |
| T-05-03 | Denial of Service | onNeedRefresh infinite loop | low | accept | useRegisterSW fires onNeedRefresh once per SW state transition; Workbox's waiting state is a one-shot event per deployment |
| T-05-SC | Tampering | npm/pip/cargo installs | low | accept | Plan 05-01 adds no new npm packages; virtual:pwa-register/react is provided by already-installed vite-plugin-pwa |
</threat_model>
