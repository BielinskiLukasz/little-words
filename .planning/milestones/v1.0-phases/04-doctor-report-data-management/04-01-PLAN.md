## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-04-01 | Information Disclosure | navigator.clipboard.writeText | low | accept | User explicitly taps Copy; content is their own child's data; clipboard is OS-sandboxed per browser security model |
| T-04-02 | Tampering | updateChildProfile on textarea blur | low | mitigate | Passes sanitized string through existing updateChildProfile service; no SQL or injection vector; IndexedDB stores plain text; service validates id is truthy before writing |
| T-04-03 | Denial of Service | useLiveQuery loading all meanings + wordForms | low | accept | Single-device, offline app; realistic data is hundreds of rows, not millions; full table scan is safe at this scale |
</threat_model>
