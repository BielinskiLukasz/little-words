## Critical Anti-Patterns (do NOT repeat these)

- **Lowercase JSX component names**: JSX tags starting with lowercase are treated as HTML intrinsic elements. Always alias imports if the export function starts with a non-uppercase letter (`import { foo as Foo } from ...`).
- **Stub-dependent tests**: When replacing a page stub with real implementation, update any tests that asserted on stub-specific text — use semantic selectors (role, label) not brittle text content.
